Contributors

Our mission is simple: no student should have to start from a blank page when someone else in their course has already made the notes. UniShare Uganda exists so that resource stays with the cohort instead of leaving with the person who made it.

Have a question?

Reach the UniShare team at hello@unishare.ug, or use the Report an Issue link on any resource page if something looks wrong.

Report an issue

Found a resource that's outdated, mislabeled, or inappropriate? Open it and use the Report button — our moderators review every report.

Terms, in short

Only upload material you created or have the right to redistribute. Content is reviewed by student moderators before it appears publicly. This is a student-built demonstration project — no real accounts or files are stored on a server.
